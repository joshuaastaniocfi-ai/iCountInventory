# iCount System User Manual

This manual provides instructions on how to use the iCount system based on your user role. The system has different capabilities and features available depending on your role.

## User Roles

The system supports the following roles:

1. **SYS-Admin (System Administrator)** - Full system access, can manage all users, companies, and system settings
2. **Company-Admin** - Can manage users within their company, approve requisitions, and manage company-specific settings
3. **WH-Admin (Warehouse Administrator)** - Can manage inventory, process requisitions, and perform warehouse operations
4. **Purchaser** - Can create and manage purchase orders
5. **User** - Basic user with limited functionality, primarily for requesting items

## Role-Specific Guides

### SYS-Admin Guide

As a SYS-Admin, you have the highest level of access in the system. Your capabilities include:

- Manage all users across all companies
- Create and manage companies
- Access all data across all companies
- Configure system-wide settings
- View and manage all requisitions
- Generate audit reports
- Manage pending removals
- View activity logs

#### Key Tasks:
- **User Management**: Accessible via the "User Management" page, you can create, edit, and delete users across all companies.
- **Company Management**: You can create new companies and manage company information.
- **System Configuration**: Configure global system settings including audit parameters and report settings.
- **Audit and Monitoring**: Access the "Activity Logs" and "Audit Stocks" sections to monitor system activity and perform inventory audits.
- **Data Management**: Access the "Pending Removals" section to review and approve deletion requests.

### Company-Admin Guide

As a Company-Admin, you have administrative capabilities within your company. Your capabilities include:

- Manage users within your company
- Approve requisitions
- Configure company-specific settings
- Generate audit reports for your company

#### Key Tasks:
- **User Management**: You can create and manage users within your company.
- **Requisition Approval**: Review and approve requisitions created by users in your company.
- **Audit and Monitoring**: Access the "Audit Stocks" section to monitor inventory accuracy.
- **Report Generation**: Generate audit reports for your company's inventory.
- **Pending Removals**: Review and approve deletion requests for items in your company.

### WH-Admin Guide

As a WH-Admin, you are responsible for warehouse operations. Your capabilities include:

- Manage inventory
- Process requisitions
- Perform stock audits
- Fulfill requisitions via mobile scanner

#### Key Tasks:
- **Inventory Management**: Use the scanner to add stock to inventory.
- **Requisition Fulfillment**: Use the mobile scanner to fulfill requisitions.
- **Stock Audits**: Perform inventory audits using the mobile scanner.
- **Pending Removals**: Submit requests to remove items from inventory.

### Purchaser Guide

As a Purchaser, your primary responsibility is to manage purchases. Your capabilities include:

- Create purchase orders
- Track purchase order status
- View inventory levels

#### Key Tasks:
- **Purchase Order Creation**: Create new purchase orders for items needed by your company.
- **Order Tracking**: Monitor the status of existing purchase orders.
- **Inventory Monitoring**: View current inventory levels to determine purchasing needs.

### User Guide

As a regular User, your capabilities are more limited. You can:

- Request items through requisitions
- View your requisition history
- View inventory levels

#### Key Tasks:
- **Create Requisitions**: Request items needed for your work.
- **View Requisitions**: Track the status of your requests.
- **Inventory Lookup**: View current inventory levels to check item availability.

## Common Workflows

### Creating a Requisition
1. Navigate to the "Requisitions" section
2. Click "Create New Requisition"
3. Select the items you need
4. Add quantities
5. Submit the requisition for approval

### Fulfilling a Requisition
1. Go to the "Scanner" section
2. Select "Fulfill Requisition"
3. Scan the items to fulfill the requisition
4. Confirm fulfillment

### Performing a Stock Audit
1. Go to the "Scanner" section
2. Select "Stock Audit"
3. Scan items in inventory
4. Compare scanned quantities with system records

### Submitting a Pending Removal
1. Go to the "Pending Removals" section
2. Click "New Removal Request"
3. Search for the item to remove
4. Enter the reason for removal
5. Submit the request for approval

## Mobile Functionality

The system supports mobile operations for warehouse tasks:

- **Mobile Audit**: Use the scanner on your mobile device to perform inventory audits
- **Mobile Fulfillment**: Use the scanner to fulfill requisitions on the warehouse floor
- **Mobile Requisition**: Create and track requisitions from mobile devices

## Troubleshooting

### Common Issues and Solutions

- **Cannot see menu items**: Ensure your role has the appropriate permissions for the functionality you're trying to access.
- **Access denied errors**: Contact your administrator to request the appropriate role or permissions.
- **Scanner not working**: Ensure you're using a supported mobile device and browser.

## Conclusion

This manual provides a comprehensive overview of the iCount system based on your user role. If you encounter any issues or have questions about your capabilities, contact your system administrator for assistance.
