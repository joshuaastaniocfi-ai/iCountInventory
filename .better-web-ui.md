## Design Context

### Users
Internal inventory staff, store managers, warehouse teams, and administrators using iCount to sign in quickly and securely before managing stock, requisitions, audits, and reports.

### Brand Personality
Focused, dependable, and modern. The login experience should feel calm, precise, and trustworthy with concise, neutral language.

### Aesthetic Direction
Black-and-white UI inspired by Supabase/Vercel: high contrast, editorial whitespace, subtle grid texture, mostly square corners with restrained rounding, and a compact split layout on wide screens that collapses cleanly on mobile. Space Grotesk is the system typeface for this surface. Avoid gradients, neon color, glossy glass effects, and decorative clutter.

### Implementation Defaults
Existing Flask + Jinja templates with vanilla CSS and Bootstrap 5. Preserve the existing Flask routes, form fields, validation, and authentication behavior. Shared authentication surfaces use the `auth-system` class and reusable monochrome styles in `static/css/auth.css`; login keeps its split layout while signup and verification flows use compact centered forms.

### Design Principles
- Establish hierarchy with spacing, weight, and contrast before decoration.
- Keep one obvious primary action: sign in.
- Use near-black and off-white neutrals with a single muted gray scale; reserve semantic colors for feedback states.
- Favor crisp borders, subtle grid texture, and restrained corner radii over gradients and heavy shadows.
- Make the form comfortable on touch devices and preserve visible keyboard focus states.
