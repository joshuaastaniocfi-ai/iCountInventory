Import from product_dict.csv

Import products directly from the product_dict.csv file located in the application root directory.

File Format Requirements
Required Fields:
  • name - Product name
  • account_title - Product category (e.g., COS-Beverages, Supplies-Kitchen)
  • uom - Unit of measure (e.g., can, bottle, kg)
  • quantity - Initial quantity (number, optional - defaults to 0)
Optional Fields:
  • item_uom_desc - Product description
  • uom_conversion - UOM conversion factor (default: 1)
  • low_stock_threshold - Low stock percentage (0-100, default: 10)
  • reorder_level - Minimum stock level that triggers reorder alert (default: 0)
  • exp_date - Expiration date (YYYY-MM-DD format)
Supported File Formats:
  • CSV (.csv) - Comma-separated values
  • Excel (.xlsx) - Microsoft Excel files
Example Format:
name,account_title,item_uom_desc,uom_conversion,uom,quantity,low_stock_threshold,reorder_level,exp_date
Coca Cola 330ml,COS-Beverages,Coca Cola 330ml can,1,can,100,10,20,2024-12-31

Paper Towels,Supplies-Kitchen,Paper towels roll,1,roll,,5,10,
